# Decision: Obsidian-ready local knowledge base

- Date: 2026-07-19
- Objective: create a portable second brain reusable across AI systems.
- Authority used: direct user request to create the store and use it as a personal assistant.
- Decision: use a local Markdown folder as the canonical source of truth, compatible
  with Obsidian, MemPalace, Graphify, and private Git version control.
- Rationale: local ownership, plain-text portability, auditable provenance, and reduced
  platform dependency.
- Tradeoff: collaboration and database views are less polished than Notion.
- Mitigation: use Notion later as a selective operational presentation layer.
- Revisit trigger: Erfan requests a different canonical store or an approved sync model.
