# Last Bench Canonical Brand Asset Lock — 2026-08-21

## Decision

For every Last Bench artifact, approved logos and brand marks are immutable canonical assets. They must never be recreated, redrawn, approximated, traced, substituted, or regenerated by an image model.

This decision exists because the same logo-regeneration failure recurred across multiple Last Bench poster attempts despite prior correction.

## Canonical Last Bench logo assets currently approved

Persistent ChatGPT Library assets:
- `master-logo-light.png` — use on light/white backgrounds; black Last Bench wordmark + green bench/rising-arrow mark on transparent canvas.
- `master-logo-dark.png` — use on dark/black backgrounds; white Last Bench wordmark + green bench/rising-arrow mark on transparent canvas.

The internal logo geometry is protected. The correct Last Bench mark includes the detailed bench construction and the specific rising-arrow/path geometry. Do not simplify it into generic horizontal bars plus an arrow.

If another later asset is explicitly approved by Erfan/Dr.X as the replacement master, that later explicit approval supersedes these filenames. Until then, these are the canonical variants.

## Incident diagnosis — 21 August 2026 agent poster

The generated agent-recognition poster failed brand integrity because the logo in the poster was not the canonical Last Bench logo. The image-generation path redrew the mark rather than compositing the approved source asset.

Observed mismatch against `master-logo-light.png`:
- bench geometry was simplified;
- the original bench legs/slats/structural relationships were not preserved;
- the arrow/path geometry was changed;
- the fine trailing line/dot detail of the canonical mark was lost;
- the wordmark was re-rendered rather than placed as the approved source.

This is a critical brand failure even if the replacement looks visually similar.

## Root cause

Failure class: **tooling + verification + requirement isolation**.

1. The full poster was sent through a generative image renderer, including the protected logo layer.
2. The logo was treated as a visual concept rather than an immutable source asset.
3. Final QC checked general appearance but did not perform a source-vs-render brand comparison.
4. A separate campaign message was allowed to bleed into the recognition poster: the friends-and-family/AI-skills CTA belongs to a different artifact unless explicitly requested for the partner-recognition creative.
5. A generated QR was included without a verified approved registration destination, which is not acceptable for a functional QR.

## Permanent production rule

Use a two-layer workflow for Last Bench creative:

`GENERATIVE VISUAL LAYER -> DETERMINISTIC BRAND/TEXT/QR LAYER -> FINAL SOURCE COMPARISON`

### Generative layer may create
- background imagery;
- people/portrait treatment when authorized;
- environment;
- decorative shapes and non-critical illustration.

### Deterministic protected layer must contain
- exact `master-logo-light.png` or `master-logo-dark.png`;
- exact names/titles/dates;
- contact details;
- campaign CTA;
- any functional QR generated from the approved URL;
- other locked Last Bench marks.

The protected layer must be composited after generation using deterministic layout/editing. The logo must never be inside the generative step.

Do not move the AI-skills CTA from the friends-and-family campaign into a partner-recognition poster unless explicitly requested.

## Mandatory acceptance test before handoff

A Last Bench branded artifact is not ready until:
- canonical source asset is retrieved;
- correct light/dark variant selected;
- logo is placed deterministically, never generated;
- aspect ratio and internal geometry are preserved;
- final render is visually compared to the canonical master;
- names, titles, event date/day, address and contacts are checked;
- campaign purpose/audience is not mixed with another asset;
- any QR decodes from the final exported artifact to the approved destination;
- final artifact itself is inspected after the last edit.

## Escalation rule

Because this failure has already repeated, any future Last Bench logo mismatch is a **process regression**. Stop the creative workflow immediately and repair the production pipeline before producing another variant.
