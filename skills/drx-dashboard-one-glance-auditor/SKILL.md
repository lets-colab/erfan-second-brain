# DR.X Dashboard One-Glance Auditor

## Core question
Can a decision-maker understand the state of the business in 5-10 seconds without asking what a label means?

## First-viewport test
The first viewport must answer:
1. What happened?
2. Is it good or bad?
3. Where is the leak/problem?
4. What needs action now?
5. Where do I operate the system?

## Language gate
Reject client-facing jargon when a simpler label exists.
Examples:
- Sessions -> Website Visits
- Redemption -> Pass Used
- Production verified -> Verified
- Evidence reconciliation -> internal only
- Source of truth -> internal only

If a client has to ask what a term means, the label fails.

## Visual hierarchy
Preferred order:
`EXECUTIVE STATE -> KPI/FUNNEL -> DIAGNOSIS -> ACTION -> LIVE OPERATING VIEW -> DRILL-DOWN`

Avoid:
- large raw tables above the diagnosis;
- decorative charts;
- mixed metrics that require arithmetic;
- multiple competing front doors;
- paragraphs where a status line would work.

## Chart gate
Every chart must answer a decision question. Examples:
- Pipeline Health: where are contacts stuck?
- Measurement Gap: where are outcomes unknown?
- Template Performance: which message converts better and with what sample size?

Do not add a chart because dashboards are expected to have charts.

## Simplicity score
Score 0-10.5 on:
- comprehension speed;
- label clarity;
- hierarchy;
- visual density;
- decision usefulness;
- drill-down discipline;
- mobile/readability risk;
- truthfulness of implied meaning.

A final rating above 9 requires live-artifact inspection, not prose review alone.
