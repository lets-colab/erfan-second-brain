# Retrieve Context Before Acting

Build enough verified context to reason correctly without flooding the reply model with
unrelated private data.

Read [references/source-ranking-and-packet.md](references/source-ranking-and-packet.md)
before combining multiple sources or using a chat backup.

## Retrieval workflow

1. Identify the target person, aliases, phone number if approved, channel, project, time
   range, and decision or reply being prepared.
2. Read the full accessible target conversation. Keep the latest exchange verbatim and
   summarize older sections by topic, commitments, emotional context, and unresolved items.
3. If older history is unavailable or material facts are missing, search approved backups
   using contact aliases, channel identifiers, project names, and date ranges.
4. Match a backup before use. Require a reliable contact identifier, channel match, or
   distinctive dated overlap. Do not merge a merely similar chat.
5. Search the Erfan Second Brain and MemPalace by concepts and aliases. Use Drive for
   source documents and backed-up conversations. Prefer primary, user-approved records.
6. Separate `FACT`, `USER_POSITION`, `EXTERNAL_CLAIM`, `INFERENCE`, and `UNKNOWN`.
7. Build the context packet. Include only information relevant to the immediate reply or
   decision. Keep private source content out of outbound text unless explicitly authorized.
8. Mark conflicts, stale facts, missing evidence, and confidence. If a missing fact could
   change a consequential answer, retrieve more or escalate.

## Drive rules

- Search first; do not guess file identity.
- Use short keyword queries and inspect metadata before fetching content.
- Prefer an exact chat export or approved project source over a broad blueprint.
- Treat documents generated by another AI as secondary claims until user-validated.
- Never interpret access to Drive as permission to disclose its contents.

## Efficiency

Reading the full conversation means understanding all available relevant history, not placing
every raw message into one prompt. Preserve exact recent messages, compress older context,
and retain source pointers for verification.
