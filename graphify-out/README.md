# Knowledge Graph Outputs

This directory contains two different classes of graph evidence. They must not be conflated.

## Current deterministic structural index

Current-state repository structure is represented by:

- `STRUCTURAL_GRAPH_REPORT.md`
- `structural-graph.json`
- root `entities.json`

These files are generated by `scripts/rebuild_knowledge_index.py` from explicit repository Markdown files, frontmatter and resolvable relative links.

A structural edge means **document A explicitly references document B**. It does not mean causality, semantic similarity, endorsement or observed business effect.

## Historical semantic Graphify output

`GRAPH_REPORT.md`, `graph.json`, `graph.html` and the historical manifest originate from the July 19 Graphify run. That corpus predates major August architecture and therefore must not be used as current-state evidence.

The original historical artifacts remain useful for reconstruction, but a fresh semantic graph requires the actual Graphify runtime to be executed against the approved current corpus and then verified.

## Truth boundary

Use the deterministic structural index for current repository navigation and coverage checks.

Use semantic Graphify relationships only after a fresh runtime execution has preserved provenance and distinguished explicit dependencies, inferred similarity, strategic hypotheses, observed relationships, historical outcomes and simulations.
